# Machine Learning Practice

A collection of **Machine Learning algorithms and techniques** practiced on different datasets. This repository documents my hands-on learning in **Data Preprocessing, EDA, Supervised Learning, Unsupervised Learning, and Model Evaluation**.

## 🧠 Topics Covered

* 📊 **Data Preprocessing:** Cleaning, Encoding, Scaling, Feature Selection
* 📈 **Regression:** Linear, Polynomial, Decision Tree, Random Forest
* 🎯 **Classification:** Logistic Regression, KNN, SVM, Decision Tree, Random Forest, Naive Bayes
* 🔍 **Clustering:** K-Means, Hierarchical Clustering, DBSCAN
* ⚖️ **Imbalanced Data:** SMOTE, Over-Sampling, Under-Sampling
* 📏 **Evaluation:** Accuracy, Precision, Recall, F1-Score, Confusion Matrix, ROC-AUC, MAE, MSE, RMSE, R²
* 🔧 **Techniques:** Feature Engineering, Cross-Validation, Model Comparison
